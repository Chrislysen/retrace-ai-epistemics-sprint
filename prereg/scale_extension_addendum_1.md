## Question

In the main run the unsafe answers of the model without a reasoning phase fell mostly on decisions that lack support
only because a copy's source is unavailable. That split was made after the results had been seen. E4 asks the same
question with the share of copies set in advance: does the rate of unsafe direct answers rise with the share of copies,
and does the compiled route stay exact?

## Cases

Twenty-four new cases with 40 records, 20 claims, 10 decisions and 3 records withdrawn, as the main run's 40-record
cases, generated by `post_sweep/scale_cases_copyshare.py` with seed 2026111602: twelve with no copies (set C0) and twelve
with 80 percent copies (set C8). The acceptance filter, prose templates, reference engine and independent check are
those of the main run; only the share of copies in the graph generator differs. The main run's own 40-record cases, with
40 percent copies, are the middle level and are not run again.

  SHA-256 `f941a4c4...d68e`

Counted on the reference before any call: set C0 has 55 unsupported decisions after the withdrawal, none of them
copy-mediated; set C8 has 60, of which 45 are copy-mediated; the main run's 40-record set has 60, of which 23 are.
"Copy-mediated" is defined as in `post_sweep/scale_error_paths.py`.

## Models, conditions, settings

Models that count as without a reasoning phase under the rule of part E1: `gemma-4-31b-it`, and `gemma-4-26b-a4b-it` if
it qualifies. If E1 is not scored when E4 starts, the second model is run and classified afterwards. Four conditions per
case: answer from the formal ledger, answer from prose, compile from prose, answer from prose with visible working.
Settings as in parts E1 and E2 (output limit 8,192 tokens, temperature 0, not streamed). 96 requests per model.

## Outcomes

Per set, model and condition: usable answers, fully correct cases, wrong decisions; unsafe answers on copy-mediated and
on direct unsupported decisions. The three shares of copies (0, 40 and 80 percent) are set side by side. What is expected
if copies drive the unsafe answers: the rate of unsafe direct answers rises with the share, and the compiled route stays
exact. The result is reported whichever way it falls. Twelve cases per set support description, not a test.
